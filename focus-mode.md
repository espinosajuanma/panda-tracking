# Focus Mode

A new feature that start a stopwatch and allow you to fill out hours before hand.

Flow:

- Click on "Focus Mode" to open the modal of the focus feature
- Set in the focus mode a project, scope, (task or ticket if scope is task or support), and a note
  - Duration must be greyed out or just hidden
- User click "Start"
- The app changes to focus mode and the stopwatch start counting up
- The user can pause and resume
- The user can minimize to keep using the app but should keep working in the background
